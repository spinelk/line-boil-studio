# Line Boil Studio

[English](README.en.md)

Herramienta web open source para aplicar un efecto de _line boil_ a ilustraciones, diseños y gráficos estáticos.

Carga una imagen, configura el movimiento y exporta el resultado como GIF o como una secuencia de imágenes. El procesamiento se realiza íntegramente en el navegador.

## Funciones

- Importación de imágenes PNG y JPEG.
- Previsualización de la imagen original y del resultado animado.
- Ajuste de amplitud, frecuencia, salto de fase y peso del efecto en los bordes.
- Control del número de frames y de la velocidad de reproducción.
- Fondo transparente o color de fondo personalizado.
- Exportación como GIF.
- Exportación de los frames individuales dentro de un archivo ZIP.

## Cómo usarlo

1. Carga una imagen.
2. Ajusta los parámetros del efecto. Las imágenes con transparencia suelen dar mejores resultados.
3. Define el número de frames, los FPS y el fondo.
4. Revisa la previsualización y exporta un GIF o un ZIP con los frames.

## Sobre el efecto

Line Boil Studio analiza los bordes de la imagen y aplica un desplazamiento ondulante a los píxeles. El resultado funciona especialmente bien con ilustraciones, dibujos y gráficos de líneas, aunque el aspecto final depende mucho de la imagen de entrada y de los parámetros elegidos.

Está orientada a generar este efecto de forma rápida y controlada; no pretende sustituir una herramienta de animación o edición completa.
