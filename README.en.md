# Line Boil Studio

[Español](README.md)

An open-source web tool for applying a _line boil_ effect to illustrations, designs, and static graphics.

Load an image, configure the movement, and export the result as a GIF or as a sequence of images. All processing takes place directly in the browser.

## Features

- PNG and JPEG image import.
- Preview of the original image and the animated result.
- Controls for amplitude, frequency, phase jump, and edge effect strength.
- Adjustable frame count and playback speed.
- Transparent background or custom background color.
- GIF export.
- Export of individual frames as a ZIP file.

## How to use it

1. Load an image.
2. Adjust the effect parameters. Images with transparency tend to produce better results.
3. Set the number of frames, FPS, and background.
4. Review the preview and export a GIF or a ZIP file containing the frames.

## About the effect

Line Boil Studio analyzes the edges of the image and applies an undulating displacement to its pixels. The result works particularly well with illustrations, drawings, and line-based graphics, although the final appearance depends heavily on the input image and selected parameters.

It is designed to generate this specific effect quickly and with control; it is not intended to replace a full animation or image-editing tool.
